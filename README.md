# Water simulation
This is another webgl project I made, in which I explore some basic particle-based water simulation. To run it, simply clone the repository and open the run.html file in your browser.

<img width="1920" height="950" alt="image" src="https://github.com/user-attachments/assets/b9ba4612-413e-4c15-bd28-ab1a4997df86" />

## Features
- Simulated particle-based water using Verlet integration
- Marching cubes
- Random terrain generation (heightmap, tree sampling)
- Ray casting for player collision detection with terrain

## Controls
- [WASD] for moving forward/backward/to the side
- [Q]/[E] for moving down/up
- [IJKL] for turning the camera
- [T] for changing the water spawnpoint to the current player position
